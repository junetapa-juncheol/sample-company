# 뉴온결 프리시전

가상 업체 포트폴리오 샘플입니다. 실제 업체의 영업·상담·모집·서비스가 아닙니다.

산업용 센서·신호 연결 모듈을 만드는 가상 B2B 제조 기업의 홈페이지입니다. 딥 페트롤과 라임 컬러로 구성합니다.

## 쪽 목록

- `index.html` — 첫 화면
- `about.html` — 회사 소개
- `products.html` — 제품·분류·사양
- `quality.html` — 품질·인증 표시 예시
- `history.html` — 가상 연혁
- `careers.html` — 가상 채용
- `contact.html` — 문의 미리보기

## 기능 체험

제품 분류 선택 → 예시 사양 열기 → 문의 화면의 예시 항목 선택 → 미리보기. 채용 직무는 펼쳐 볼 수 있습니다. 실제 제품·보유 인증·채용·문의 접수는 제공하지 않습니다. 모든 수치·연혁은 가상 예시입니다.

## 사용 기술

HTML5 · CSS3 · Vanilla JavaScript. 글꼴은 Google Fonts의 Noto Sans KR을 요청하며 글꼴 파일은 저장소에 포함하지 않습니다. 글꼴을 가져올 수 없으면 시스템 sans-serif를 사용합니다. 키보드 포커스·모바일 메뉴·움직임 줄이기 설정을 지원합니다. 분석 스크립트·외부 폼·결제 연동이 없습니다.

이미지: `images/` 폴더의 사진.
